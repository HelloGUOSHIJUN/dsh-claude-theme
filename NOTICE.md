# Notice

## Design values

The palette, radii, elevation and type scale in this theme are derived from the
Claude Design System token set as documented and reproduced by
[open-claude-ui](https://github.com/Caho1/open-claude-ui) (MIT licensed).

Only numeric values (colour ramps, radii, shadows, easing curves) are reused.
No source code from that project is included.

## Fonts

No font files are bundled. The theme references font families already present
on the user's system (`Songti SC`, `STSong`, `Georgia`, `Times New Roman`) and
falls back to the platform serif.
