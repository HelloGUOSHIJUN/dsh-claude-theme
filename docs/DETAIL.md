# Claude 主题

把 DeepSeek Harness 的 Web 界面换成 Claude 的视觉语言。通过覆盖 Harness 自带的主题令牌，再加一层组件级 CSS 实现。它不改动会话、工具或快捷键的任何行为。

## 两层的改动

**第一层：令牌（整站生效）**

| 维度 | 默认 | 本主题 |
| --- | --- | --- |
| 画布 | `#fff` / `#151517` | `#faf9f5` / 暗色 `#151515` |
| 侧栏 | 冷灰 | `#f0eee6` / 暗色 `#0b0b0b` |
| 卡片、输入框 | 冷灰白 | `#fff` / 暗色 `#1a1a19`–`#20201f` |
| 边框 | 近黑透明 | `rgba(11,11,11,.06–.18)`，暗色 `rgba(255,255,255,.07–.22)` |
| 强调 | DeepSeek 蓝 | Claude 蓝（链接、焦点环）+ 陶土橙 `#c6613f`（闪点、选区） |
| 灰阶 | 带蓝 35 阶 | 暖灰 35 阶 |
| 圆角 | 4/8/12/16/20/28 | 4/6/8/10/12/14/16/18（输入框 14、气泡 18、控件 8、面板 10） |
| 投影 | 中性双阴影 | 暖色低透明度柔光 |
| 排版 | 14/24、标题 700 | 固定 17px、行高 1.6、标题 600 |
| 动效 | — | CDS 5 阶时长（60/120/200/300/450ms） |

**第二层：组件形状**（`[data-composer-card]`、`[data-message-bubble]` 等稳定钩子）

- 输入卡片：14px 圆角、单条发丝描边、`0 4px 20px` 的柔和投影（Claude 的 composer 形态）。
- 用户消息：18px 圆角、`12px 16px` 内边距、行高 1.6 的暖灰气泡。
- 侧栏：平面暖纸；去掉侧栏与正文之间的竖直分割线；品牌字标行隐藏，侧栏直接以「新对话」开头。
- 标题 600 字重 + 轻微收紧字距；限定 `::selection` 为陶土橙、光标与占位符弱化。

## 已知的界面变化

这一版除了换色，还**主动改动了几处界面结构**。安装前请确认这些是你想要的：

| 变化 | 影响 |
| --- | --- |
| **全局字体改为衬线（宋体）** | 正文、侧栏、菜单全部使用 `Noto Serif SC / Songti SC` 字体栈，不再是系统默认无衬线字体。这是刻意的风格选择，但会明显改变阅读观感。 |
| **字号固定 17px** | 覆盖 **设置 → 外观** 里的字号设置，调大调小都不再生效。 |
| **品牌字标行隐藏** | 侧栏顶部的品牌行被 `display:none` 移除。 |
| **输入框状态信息隐藏** | `[data-composer-stat]`（输入框下方的状态提示）被隐藏。 |
| **对话标签页改为胶囊分段控件** | 视图切换器从原生标签条变成 999px 胶囊轨道。 |
| **消息操作 tooltip 上翻** | 操作行的 tooltip 改向上弹出，避免被常驻输入框遮挡。 |

## 使用

1. 安装后在 **插件** 中确认 `Claude theme` 已启用。
2. 刷新页面（`⌘R`）。
3. 亮/暗色跟随 **设置 → 外观**；**字号设置不再生效**（见上表）。
4. 想还原：停用 `Claude theme` 后刷新。

## 边界

- 不改变会话逻辑、工具行为与快捷键。
- 组件层依赖 DSH 当前的数据钩子与类名主干；DSH 大改版后个别形状规则可能失效，令牌层仍会生效。
- 部分把颜色写死在组件里的区域（少数第三方面板、Shiki 高亮的个别 token）不会跟随。
- `:has()` 选择器未做 `@supports` 兜底，在超长会话快速滚动时可能有轻微性能开销。
- 未实现 CDS 3.0 的 `@property` 驱动滚动渐隐、`data-mode` 三态作用域与 55 项关键帧：这些需要宿主容器配合，本主题不做。

## 来源

色板、圆角、阴影与排版密度取自 [open-claude-ui](https://github.com/Caho1/open-claude-ui)（MIT）还原的 CDS 令牌，并按该项目的 v4 取证报告（Claude Desktop 3.6556.2 / 4.4212.0）校正。主题只使用这些数值，不含该项目的组件代码。

关键取值：`--cds-gray-850 #151515`、`--cds-gray-830 #1a1a19`、`--cds-gray-800 #20201f`、`--cds-clay #d97757`、`--cds-clay-emphasized #c6613f`、5 阶时长 `60/120/200/300/450ms`。
