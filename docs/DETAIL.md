# Claude 主题

把 DeepSeek Harness 的 Web 界面换成 Claude 的视觉语言。主题覆盖 Harness 自带的主题令牌，再加一层组件级 CSS。会话、工具和快捷键的行为都不变。

## 两层的改动

**第一层：令牌（整站生效）**

| 维度 | 默认 | 本主题 |
| --- | --- | --- |
| 画布 | `#fff` / `#151517` | `#faf9f5` / 暗色 `#151515` |
| 侧栏 | 冷灰 | `#f0eee6` / 暗色 `#0b0b0b` |
| 卡片、输入框 | 冷灰白 | `#fff` / 暗色 `#1a1a19`–`#20201f` |
| 边框 | 近黑透明 | 亮色 `rgba(11, 11, 11, 0.05～0.35)`，暗色 `rgba(255, 255, 255, 0.05～0.35)` |
| 强调 | DeepSeek 蓝 | 链接（含文件链接）用品牌陶土 `#c6613f`，暗色 `#e0895f`。按钮的焦点环用陶土橙 `#c6613f` / `#d97757`。选区是陶土色 |
| 灰阶 | 带蓝 35 阶 | 暖灰 35 阶 |
| 圆角 | 4 / 8 / 12 / 16 / 20 / 28 | 4 / 6 / 8 / 10 / 12 / 14 / 16 / 18（输入框 14、气泡 18、控件 8、面板 10） |
| 投影 | 中性双阴影 | 暖色低透明度柔光 |
| 排版 | 14/24、标题 700 | 17px 起步、行高 21px（随字号同幅增加）、标题 700。设置 → 外观 的字号在 17px 基线上叠加 |
| 动效 | — | CDS 时长（60 / 120 / 200 / 300 ms） |

**第二层：组件形状**（`[data-composer-card]`、`[data-message-bubble]` 等稳定钩子）

- 输入卡片：14px 圆角、单条发丝描边、`0 4px 20px` 的柔和投影，Claude 的 composer 形态。
- 用户消息：18px 圆角、`12px 16px` 内边距、行高 1.6 的暖灰气泡。
- 侧栏：平面暖纸；去掉侧栏与正文之间的竖直分割线；主题隐藏品牌字标行，侧栏直接以「新对话」开头。
- 标题 700 字重，字距轻微收紧；`::selection` 改为陶土橙，光标与占位符弱化。

## 已知的界面变化

这一版除了换色，还改了几处界面结构。安装前请确认这些是你想要的：

| 变化 | 影响 |
| --- | --- |
| **全局字体改为衬线（宋体）** | 正文、侧栏、菜单全部使用 `Noto Serif SC / Songti SC` 字体栈，不再是系统默认的无衬线字体。这是刻意的风格选择，但会明显改变阅读观感。 |
| **正文 17px 起步** | 正文字号从原生 14px 改为 17px。设置 → 外观 的字号调节依然有效，所选字号叠加在 17px 基线上。 |
| **品牌字标行隐藏** | 主题用 `display:none` 移除侧栏顶部的品牌行。 |
| **输入框状态信息隐藏** | 主题隐藏 `[data-composer-stat]`，即输入框下方的状态提示。 |
| **对话标签页改为胶囊分段控件** | 视图切换器从原生标签条变成 999px 胶囊轨道。 |
| **消息操作 tooltip 上翻** | 操作行的 tooltip 改向上弹出，避免被常驻输入框遮挡。 |
| **任务面板间距已调整** | 输入框上方的待办面板与输入卡片之间留出 8px 间隙（原生用负外边距把两者挤在一起），面板内最后一条任务也不再贴住卡片底边。 |
| **列表板块不显示悬停底色** | 设置页、插件页、会话列表里整块的行和卡片，鼠标悬停时不再变色（整块变色像布局在晃，卡片还会溢出边界）。开关、按钮、链接自己的悬停反馈保留。 |
| **代码块底角、步骤勾、回到底部按钮** | 代码块外框 12px 圆角，底角跟着 `<pre>`；工具步骤的完成勾恢复宿主的 16px 圆圈；回到底部圆钮按宿主原尺寸 34px 显示。 |
| **交付文件卡片** | 附件卡片为 10px 圆角、暖色 1px 描边，图标是暖沙底加陶土橙。卡片上的「打开 / 下一级」分体按钮改为直角分块、直线接缝，整体 30px 高。 |
| **四列以上表格固定为正文宽度** | Harness 会把 4 列及以上的表格当成宽表铺满对话区。主题把它钉回正文列宽，表格内自动换行；仍放不下的保留横向滚动。3 列及以下的表格外观不变。 |

## 使用

1. 安装后在插件中确认 `Claude theme` 已启用。
2. 刷新页面（`⌘R`）。
3. 亮色和暗色跟随设置 → 外观。字号设置依然生效，会叠加在 17px 基线上。
4. 想还原：停用 `Claude theme` 后刷新。

## 边界

- 不改变会话逻辑、工具行为和快捷键。
- 组件层依赖 DSH 当前的数据钩子与类名主干；DSH 大改版后个别形状规则可能失效，令牌层仍会生效。
- 部分把颜色写死在组件里的区域不会跟随主题配色，比如少数第三方面板和 Shiki 高亮的个别 token。
- `:has()` 选择器未做 `@supports` 兜底，超长会话快速滚动时可能有轻微性能开销。
- CDS 3.0 的 `@property` 滚动渐隐、`data-mode` 三态作用域和 55 项关键帧尚未实现，需要宿主容器配合，本主题不做。

## 来源

色板、圆角、阴影与排版密度取自 [open-claude-ui](https://github.com/Caho1/open-claude-ui)（MIT）还原的 CDS 令牌，并按该项目的 v4 取证报告（Claude Desktop 3.6556.2 / 4.4212.0）校正。主题只使用这些数值，不含该项目的组件代码。

关键取值：`--cds-gray-850 #151515`、`--cds-gray-830 #1a1a19`、`--cds-gray-800 #20201f`、`--cds-clay #d97757`、`--cds-clay-emphasized #c6613f`、时长 `60 / 120 / 200 / 300 ms`。
